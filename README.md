# Roll-a-Ball

A simple 3D game built in Unity where you roll a ball around a play area to collect pickups. Collect them all to win!

This project was made by following Unity's official [Roll-a-Ball tutorial](https://learn.unity.com/project/roll-a-ball) as an introduction to Unity and C#.

## Features
- Physics-based player movement
- Collectible pickups with a score counter
- Win message when all pickups are collected

## What I Learned
- Setting up scenes, GameObjects, and components
- Moving a player with Rigidbody physics and the Input System
- Writing C# scripts for movement, collisions, and UI
- Using triggers and tags to detect collectibles
- Making the camera follow the player

## How to Run
1. Clone this repository
2. Open the folder in Unity Hub
3. Open the main scene in `Assets/Scenes`
4. Press Play

## Controls
- **WASD / Arrow keys**: move the ball
